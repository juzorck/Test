# Система баллов для домашних задач

Простое приложение для распределения бытовых задач между партнерами с системой баллов и наград.

## Установка

```bash
pip install -e .
```

## Запуск

```bash
run
```

или

```bash
uvicorn backend.main:app --reload
```

Доступно по адресу: http://localhost:8000

## Функции

- Два пользователя: "Вы" и "Девушка"
- Добавление задач с указанием количества баллов
- Получение баллов за выполнение задач
- Обмен баллов на награды
- Статистика выполненных задач
